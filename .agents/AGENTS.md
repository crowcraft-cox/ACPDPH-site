# Workspace Behavioral Guidelines & Rules

## UI & Design Rules
- **NO EMOJIS**: Il est strictement interdit d'utiliser des émojis Unicode (ex: 🚀, ✨, ❌, 💡, 📰, 📷, ✉️, 🛡️, 🔄, 🗑️) dans le texte, les boutons, les titres, les cartes ou l'interface.
- **Iconographie SVG Moderne**: Utiliser systématiquement des icônes SVG Inline ultra-propres (heroicons / lucide) ou des badges typographiques soignés (spans colorés, pastilles d'état, boutons d'action).
- **Design Épuré & Professionnel**: Maintenir une esthétique premium, moderne et professionnelle sans aucun émoji.
